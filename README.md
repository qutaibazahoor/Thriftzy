# Gainszee

Premium pre-loved sneakers and streetwear e-commerce platform.

## Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Language**: TypeScript

## Features

- 🎨 Apple-style minimalist design
- ✨ Smooth Framer Motion animations
- 📱 Fully responsive
- 🛒 Product catalog with categories
- 📄 Product detail pages with purchase policies
- 🏷️ Size badges and condition indicators

## Pages

- `/` - Homepage with hero, featured drops, and product grid
- `/shop` - Full product catalog
- `/product/[id]` - Product detail page
- `/about` - Brand story and values

## Design Philosophy

- **Radical Minimalism**: The product is the hero
- **Monochromatic Palette**: White, black, and grey
- **Typography First**: Inter font with massive headers
- **Generous Whitespace**: Clean and premium feel
